# NAI Comic Studio — автономное расширение для SillyTavern

**Версия 0.1.0-beta.** Независимое расширение для NovelAI Diffusion V5 Full и Qwen (через существующий SillyTavern Connection Profile). Пишет иллюстрации к ролке, **не создавая нового текстового ответа персонажа**. Этот код не является патчем существующих `sillyimages` или `ExtBlocks`.

## Возможности

- **Библиотека персонажей и персон:** основное описание + включаемые дополнительные описания; автоматический выбор по активному чату/аватару персонажа и активной персоне SillyTavern. Описания хранятся отдельно от сцены.
- **Одноразовое объединение:** программа собирает ровно две независимые секции NovelAI `v4_prompt.caption.char_captions` (персонаж и персона); не просит Qwen переписывать внешность, не добавляет третью секцию в конец.
- **Импорт из старой библиотеки:** кнопка считывает данные из `extensionSettings.inline_image_gen` (не изменяя оригинал), переносит все текстовые описания, сохранённые стили, негативы и, если есть, ключ NovelAI. Образцы картинок не передаются в V5: NovelAI V5 в этой интеграции использует текстовую внешность.
- **Автоматическое переключение чатов:** отдельные анкеты связаны с идентификатором аватара/карточки, а персоны — с активным аватаром пользователя.
- **Библиотеки стилей и негативов:** независимые сохранённые пресеты, активный стиль и активный негатив. Импорт из прежнего расширения.
- **Сцена от Qwen:** выбранный Connection Profile берёт последние 7 сообщений и одежду из WTracker при наличии, пишет только сцены/панели, текущую одежду, действия и эмоции. Также есть полностью ручной режим.
- **Бесплатный предпросмотр:** полная финальная положительная строка и тело JSON-запроса NovelAI (включая обе анкеты) показываются до нажатия кнопки генерации.
- **Отладка:** список событий, последняя JSON-заявка и экспорт диагностики без API-ключа.
- **Изображения:** сохранение в SillyTavern, отображение последней картинки, по желанию прикрепление к уже существующему сообщению персонажа; ручная или автоматическая генерация. **Автогенерация изначально выключена**.

## Установка через GitHub без доступа к серверным файлам

1. Создайте **новый** репозиторий GitHub, например `nai-comic-studio-st` (не нужно делать fork `sillyimages`).
2. Распакуйте архив. Загрузите содержимое папки **в корень репозитория**: `manifest.json`, `index.js`, `core.mjs`, `style.css`, `README.md`. Не оставляйте лишнюю верхнюю папку.
3. В браузерной SillyTavern откройте **Extensions → Install extension**, вставьте ссылку `https://github.com/ВАШ-НИК/nai-comic-studio-st`. Если установщик поддерживает «Install for yourself», выберите этот вариант.
4. Перезагрузите страницу (`Ctrl+F5`). В «Расширениях» будет панель **NAI Comic Studio**.
5. Чтобы избежать двойной генерации, **выключите** прежний `sillyimages`/его форк, а также генерацию `naicom` в ExtBlocks. Удалять их и стирать их настройки не нужно.
6. Откройте **NAI Comic Studio**, нажмите **«Импортировать внешность, стили и негативы из старого генератора»**. После импорта проверьте обе активные анкеты.
7. При необходимости вставьте ключ NovelAI, выберите Connection Profile Qwen. При использовании ручной сцены Qwen не нужен.
8. Нажмите **«Получить сцену» → «Показать полный запрос»**. Проверьте две секции персонажей. **Только после этого** нажмите **«Создать картинку»** (расходует Anlas).

### Ограничения и безопасность

- Это **бета-версия, проверенная статически и модульными тестами**, но ещё не протестированная внутри пользовательского сервера SillyTavern и с реальным API NovelAI. Доступность прямого запроса `https://image.novelai.net/ai/generate-image` зависит от сети/CORS и конфигурации сервера. В исходном расширении использовался такой же URL.
- Ключ NovelAI хранится в настройках SillyTavern для этого расширения; **не записывайте ключ в файлы GitHub**. Экспорт настроек и диагностики ключ исключает.
- Не меняет и не удаляет старые анкеты `inline_image_gen`; импорт создаёт отдельную копию.
- NovelAI V5 не гарантирует точную передачу лица или разных цветов глаз только из текста. Две секции снижают смешивание, но полностью не исключают его.
- Отправка запроса Qwen из браузера использует подключение, выбранное в `Connection Profiles` SillyTavern. Для Qwen через нестандартные прокси может требоваться адаптация к вашему серверу.
- Функция автогенерации может тратить Anlas на **каждое** новое сообщение персонажа. Она отключена до ручного включения.

## Устройство пакета

- `manifest.json`: подключение к SillyTavern.
- `index.js`: панель управления, подключение к Qwen и NovelAI, переключение персонажей и загрузка изображений.
- `core.mjs`: независимая логика подготовки двух описаний и API-запроса (удобна для тестов).
- `style.css`: оформление панели.
- `core.test.mjs`: тесты логики (не обязателен для работы).

## Модельное построение (наглядно)

```
Короткая текущая сцена Qwen → только BASE
Анкета персонажа (библиотека) + его одежда и действие → CHAR 1
Анкета активной персоны (библиотека) + её одежда и действие → CHAR 2
Отдельный активный стиль → BASE
Отдельный негатив → V5 negative_prompt
```

Никакие анкетные данные не дублируются автоматически в `BASE`.
